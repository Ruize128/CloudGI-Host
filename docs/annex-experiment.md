# Annex 子会话实验

分支：`feature/annex-child-session`。首页“使用独立后台桌面”开关默认开启，自动保存到现有 settings.json，重启 Host 后生效。开启时子会话失败不会回退到物理桌面；关闭时恢复主桌面模式。

## 使用

1. 在 Windows 11 Pro 或更高版本正常编译、启动 Host，确认既有 UAC 提示。
2. 开启独立后台桌面时，Host 自动打开后台桌面查看器。在专用登录窗口输入当前 Windows 账户密码，不是 Hello PIN；密码仅用于本次连接，不保存到文件或日志。
3. 等待 Host 的串流状态变为“可连接”。手机继续使用现有 Client 自动发现、配对和启动游戏。
4. 查看器可以最小化到托盘，必须保持 RDP 连接。关闭查看器会注销它创建的子会话，结束其中的全部应用。
5. 设置页的“Annex 后台桌面”可以指定宽、高、缩放。请先断开串流并关闭游戏；应用设置会重建后台桌面。

关闭该开关并重启后，主 Host 直接启动随附 Sunshine，游戏启动、输入和状态检测都在主桌面；不创建子会话或子 Host。
两种模式的串流配置、身份与配对记录分别保存在 Host\Sunshine 和 Host\Annex\Sunshine，游戏配置、编码选项及主 Host 的模式开关保存在同一份 settings.json；子 Host 的运行角色固定，不会读取模式开关来创建子会话。子 Host 首页禁用该开关，配置访问层也固定返回关闭并保留主 Host 原有值，保存游戏或编码选项时不会覆盖主 Host 的模式。
主窗口在同一个 Windows 登录会话中只允许一个实例，子 Host 与防火墙辅助进程不受该限制。

独立桌面使用同一个 Windows 账户，不是文件/账户安全沙盒。系统已有 BetterGI/Annex 子会话时会拒绝创建，不会接管或注销已有会话。

## 编码方式

首页“使用硬件编码”自动保存到共用的 settings.json，重启 Host 生效，对主桌面和子会话模式均有效。默认关闭，使用 H.264 软件编码。
开启时由 Sunshine 检测硬件编码器，Host 会核对实际选择；如果 Sunshine 回退到软件编码，Host 会停止该实例并报告硬件编码不可用。首页会显示已确认的实际编码器。
不再依据 Parallels 硬件标识强制覆盖用户选择。PD 缺少可用硬件编码器时，请保持开关关闭。

## 结构

- 主桌面 WinUI Host：设置和状态界面；通过仅限当前用户的命名管道管理子会话代理。
- `CloudGI.Host.Session`：基于固定 Annex 源码的 RDP ActiveX 查看器，保持子会话显示器存活。
- 子会话内 `CloudGI.Host --child-session-agent`：自动显示子 Host 窗口，直接管理专属 Sunshine、自动配对/控制接口、游戏启动、手机 UI 和断线清理；主 Host 通过管道调用同一组服务。窗口标题和当前模式明确标识后台桌面。
- Sunshine 使用 WGC 捕获子会话桌面；编码方式由首页“使用硬件编码”统一选择；游戏检测和 PID 身份检查仍限定代理所在的会话。
- 使用一次性、同用户的最高权限交互式任务启动代理；不创建 SYSTEM 服务或开机启动项。代理成功连接后删除临时任务。手动在子会话中运行普通 Host 会被启动入口拦截，不能再次创建子会话；关闭子 Host 会结束代理与串流服务。

后台数据位于 `%LOCALAPPDATA%\CloudGI\Host\Annex`，与原来主桌面的 Sunshine 身份和凭据分开；游戏路径设置共用。
Sunshine 启动失败时保留已登录的后台桌面，点击重新启动可复用该会话；无需再次输入 Windows 密码。
查看器只调用 Windows 子会话 API，并临时设置 RDP 最小化时继续渲染，正常退出时恢复原值。
本实验不运行上游安装脚本，不自动开放 RDP 防火墙、修改 Windows Hello/UAC 或安装虚拟显示驱动。
如果系统禁止本机 RDP 或账户无法登录，界面会报告失败，需要根据实际错误处理系统前提。

## 验收

首先验证不打开游戏的桌面串流：Sunshine/代理的 SessionId 应等于子会话 ID，并与主桌面不同；手机触控不应改变主桌面焦点。
随后验证指定手机比例、最小化查看器、硬件编码/音频和多点触控，最后复用现有原神手机 UI 与断线退出流程。
子会话可能不会继承主会话的映射网络盘。NAS 游戏目录若无法访问，可使用相同共享的 UNC 路径并核对该账户的网络访问权限。
Windows ARM64/Parallels 可验证会话与控制链路；GPU 性能和实际并行使用应在 Windows 台式机验证。

子会话连接、GPU 编码、原神及手机 UI 的运行兼容性须分别实测；编译和核心单元测试不等于这些项目已通过。
